1. 계정에 저장하는 정보

소셜 제공자명과 고유 계정 식별자, 제공자가 전달한 이름·이메일·이메일 확인 여부, 가입 시각, 수정한 이름, 약관·개인정보 동의 버전과 시각, 선택 동의 상태를 계정 식별과 관리 목적으로 서버에 저장합니다. 소셜 비밀번호는 입력받거나 저장하지 않습니다.

2. 인증 정보

로그인 세션의 식별자, 기기 구분, 생성·최근 사용·만료 시각을 저장합니다. 세션 토큰은 서버에서 해시로 저장하고, 웹에서는 HttpOnly 쿠키, 앱에서는 운영체제의 보안 저장소로 관리합니다. 제공자 연결 해제에 필요한 토큰은 서버에서 암호화해 저장합니다.

3. 위치와 경로 검색

현재 위치 버튼·재탐색 또는 자동 이동 감지 켜기를 선택할 때 위치 권한을 요청합니다. 자동 감지는 기본으로 꺼져 있으며 허용한 이동 안내 중에만 위치와 기기 활동 정보를 사용합니다. 좌표와 출발·도착 지점은 경로 계산에 사용하며 검색할 때 계정 이력에 자동 저장하지 않습니다. 실제 장소 검색어와 경로 요청 좌표는 카카오 API에 전달됩니다. 서버는 위치·검색어·공급원 응답 내용을 요청 로그에 남기지 않습니다. 과도한 요청 제한을 위해 접속 IP 주소를 서버 메모리에서 일시적으로 사용합니다.

4. 이동 기록과 설정

이동 설정, 저장 경로 최대 10개, 최근 검색 최대 5개, 도착을 확인한 최근 안내 최대 20개, 목적지 메모와 알림 설정을 현재 기기에 저장합니다. 도착 기록에는 출발·도착 이름, 안내 시작·확인 시각, 준비 여유와 마감, 시연 여부를 보관하며 실제 GPS 이동 궤적은 보관하지 않습니다. 자동 감지의 GPS 원본은 최대 5개의 최근 표본을 기기 메모리에서만 처리하고 디스크나 외부 AI 서버로 전송하지 않습니다. 화면이 꺼져도 이어가기 위한 감지 캐시에는 진행 중인 경로·현재 단계·마지막 감지 결과·세션 시각을 일시 저장하며 안내 종료·감지 끄기·기기 데이터 초기화 때 삭제합니다. 안내 복원을 위한 별도 기록에는 출발·도착 좌표, 공급원 경로 선과 현재 단계·마감·센서 선택을 기기에 저장합니다. 감지를 끈 뒤에도 안내는 이어갈 수 있으며 이 복원 기록은 안내 종료·도착 확인·기기 초기화 때 삭제합니다. 중단된 세션은 최대 8시간 뒤 만료 시 정리합니다. 현재 앱은 이 기록을 다른 기기로 자동 동기화하지 않습니다. 회원 계정의 기록 저장 요청을 이용한 경우 이동 설정과 경로의 출발·도착 이름, 좌표, 메모, 저장 시각을 서버에 보관할 수 있습니다. 기기 기록 삭제는 서버 계정 기록의 삭제와 별개이며, 계정 기록은 탈퇴 완료 시 삭제합니다.

4-1. 선택적인 이동 시간 학습 · 2026-11-02 변경

개인정보와 기기 데이터 화면에서 이동 시간 학습을 따로 켠 경우에만 수집해요. 새로 시작해 목적지 도착까지 마친 실제 안내에서 구간 시작·완료 시각, 이동수단, 거리, 예상 소요, 실제 소요, 확보한 날씨·도로·환승 대기 정보를 경로 소요 예측을 개선하려고 학습 서버에 보내요. 구간 시각은 기기가 위치·속도·실시간 도착 정보로 판정한 시각이고, 직접 넘긴 단계는 넘긴 시각이에요. 출발부터 도착까지의 전체 시간은 도착을 직접 눌러 확인한 경우에만 보내요. 이 수집은 기본으로 꺼져 있고, 가입이나 길찾기의 필수 조건이 아니에요. 학습 데이터베이스에는 정밀 좌표, 장소 이름, 계정·성명, 원시 GPS와 활동 센서 기록을 저장하지 않아요. 시연·중단·백그라운드 전환·복원·재탐색이 있었던 이동은 수집하지 않아요. 시작이나 끝을 확인하지 못하고 넘어간 구간과 예정 시간으로 넘어간 구간은 빼고 보내요. 구간 기록은 서버 정리 때 최근 90일 이내로 유지하고, 모델은 30일이 지나면 적용하지 않아요. 설정에서 수집을 끄거나, 이 기기에 남은 삭제 권한으로 전송한 기록을 지울 수 있어요. 실제 기록이 지워지면 관련 모델은 다시 검증하기 전까지 꺼 둬요. 앱을 지우기 전에 서버 기록 삭제를 먼저 끝내 주세요. 기기의 판정이나 직접 넘긴 시각은 독립적으로 인증한 물리적 이동을 뜻하지 않아요.

5. 지도와 외부 연결

지도는 OpenStreetMap 자료로 만든 Protomaps 지도 파일과 국토지리정보원 수치지형도를 MapLibre로 표시합니다. 기본 지도 파일은 지각지도가 Google Cloud Storage에 올려 제공하고, 수치지형도는 지각지도 서버를 통해서만 제공합니다. 글꼴과 지도 기호는 Protomaps가 GitHub Pages에 공개한 자료를 내려받습니다. 이 과정에서 Google과 GitHub에 IP 주소와 요청한 지도 영역이 전달될 수 있습니다. 보행망 경로를 조회하면 선택한 출발·환승·도착 좌표가, 따릉이 경로를 조회하면 대여·반납 대여소 좌표가 경로 서버를 통해 FOSSGIS의 OpenStreetMap/OSRM 경로 서버에 전달됩니다. FOSSGIS는 요청을 서버 로그에 기록하며 해당 공급원의 처리방침이 적용됩니다. 외부 지도나 소셜 로그인 페이지를 열면 해당 서비스의 처리방침이 적용됩니다.

6. 문제 신고

신고 분류, 내용, 선택 입력한 이메일, 접수 시각을 문제 확인 목적으로 서버에 보관합니다. 로그인 여부와 관계없이 신고는 계정 식별자와 연결하지 않고 접수합니다. 신고 내용에 비밀번호, 인증 코드, 주민등록번호, 상세한 사생활 정보를 넣지 마세요. 신고는 90일이 지난 뒤 서버 정리 시 삭제됩니다. 신고는 계정과 연결하지 않으므로 계정 탈퇴로 삭제되지 않습니다.

7. 보유 기간과 삭제

계정 정보와 연결 해제에 필요한 인증 정보는 탈퇴 완료 시 삭제합니다. 로그인 세션은 최대 7일 후 만료합니다. 로그인 요청은 5분, 일회용 연결 티켓은 2분 뒤 만료하며, 가입 동의를 마치지 않은 계정은 24시간 후 정리 대상이 됩니다. 기기 기록은 직접 삭제하거나 앱 데이터를 지울 때 삭제됩니다.

8. 이용자 선택

선택 동의를 거부해도 필수 서비스를 이용할 수 있습니다. 계정 화면에서 이름 수정, 세션 해제, 로그아웃 및 탈퇴가 가능합니다. 자동 감지는 앱 설정과 이동 안내에서 끌 수 있습니다. 위치·기기 활동·알림 권한은 기기 설정에서 철회할 수 있으며, 위치 권한을 거부한 경우 출발지를 직접 검색할 수 있습니다. 선택 동의는 저장하지만 현재 광고·마케팅 발송 기능은 없습니다.

9. 공개 운영 전 확정할 사항

운영자와 보호 담당자 연락처, 수탁자 및 국외 이전 여부, 권리 행사·보존 의무·침해 대응 절차, 만 14세 미만 이용 정책을 확정하고 실제 운영 환경에 맞게 검토해야 합니다. 현재 문서의 버전은 가입 동의 이력과 함께 기록합니다.
