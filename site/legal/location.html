언제 위치를 확인하나요?

현재 위치를 출발지로 선택할 때, 현재 위치로 다시 경로를 찾을 때 전경 위치를 확인합니다. 자동 감지를 켠 이동 안내 중에는 위치와 기기 활동 정보를 확인합니다. 백그라운드 위치 권한을 허용하면 화면이 꺼져도 확인하며, 안내를 끝내거나 감지를 끄면 중지합니다.

어디에 전달되나요?

경로 검색·재탐색 때 선택한 좌표는 지각지도 경로 서버와 필요한 카카오 경로 API, FOSSGIS의 OpenStreetMap/OSRM 보행망·자전거망 서버에 전달됩니다. 보행망 조회에는 출발·환승·도착 지점만, 자전거망 조회에는 따릉이 대여소 위치만 사용합니다. 자동 감지의 연속 GPS와 활동 자료는 기기에서만 처리하며 서버로 보내지 않습니다. 위치 오차가 150m를 초과하면 정확한 장소를 직접 고르도록 안내합니다. 검색할 때 서버 계정의 위치 이력에 자동 저장하지 않으며, 회원 계정으로 경로 기록을 별도 저장한 경우에는 해당 경로의 좌표가 포함될 수 있습니다.

기기에 남는 정보

자동 감지의 원본 GPS 표본은 메모리에서만 처리합니다. 현재 이동의 경로·단계·마지막 감지 결과는 기기에 잠시 보관하고 안내 종료·감지 끄기 때 삭제합니다. 현재 위치를 포함한 경로를 별도로 저장하거나 최근 검색에 남기면 좌표가 기기 기록에 포함될 수 있습니다. 개인정보와 기기 데이터 화면에서 해당 기록을 삭제할 수 있습니다.

권한과 안내 종료

기기 설정에서 위치 권한을 끌 수 있습니다. 앱으로 돌아오면 운행·교통 자료를 다시 불러옵니다. 앱 강제 종료나 절전 정책으로 감지가 중단될 수 있습니다. 잠금 화면의 표시는 마지막으로 확인한 상태이므로 실시간 위치나 정확한 도착 시각을 의미하지 않습니다.
